<task type="auto">
  <name>Task 2: LinkPreviewCard — lê o cache, dispara a busca uma vez, desenha o cartão</name>
  <files>src/renderer/src/components/shell/LinkPreviewCard.tsx</files>
  <action>
    Componente `LinkPreviewCard({ url }: { url: string })`:
    - `const preview = useQuery(api.linkPreviews.getPreview, { url })`.
      `undefined` = carregando, `null` = sem cache ainda, documento = tem dado.
    - `const fetchPreview = useAction(api.linkPreviews.fetchPreview)`.
      Num `useEffect`, disparar `fetchPreview({ url })` **uma única vez**,
      quando `preview === null` (cache frio) — com um `useRef` de guarda para
      não redisparar quando o componente remonta por causa de scroll/paginação
      da lista. A subscription da query atualiza sozinha quando a action grava.
      **Guarda que só marca sucesso não protege o caminho de falha** (lição
      nº 3 do HANDOFF.md): marcar o `ref` ANTES de chamar a action, não no
      `.then`. Se a action falhar, ela mesma já gravou `failed` no cache do
      lado do servidor — não tentar de novo aqui.
    - Renderização:
      - `preview === undefined` ou `null` → renderizar `null`. Nada de
        esqueleto/placeholder: a mensagem não pode mudar de altura depois de
        lida (o app tem lógica de scroll sensível a isso — CHAT-04/CHAT-14, já
        verificados).
      - `status === 'failed'` → renderizar `null`. Link quebrado não vira
        cartão vazio.
      - `status === 'ok'` → `Card` com borda `border-border`, largura máxima
        (~28rem) e `<a href={url} target="_blank" rel="noreferrer">` em volta
        do conteúdo clicável (o `setWindowOpenHandler` do processo main manda
        para o navegador padrão):
        - `siteName` em `text-xs text-muted-foreground`
        - `title` em `font-medium`, `line-clamp-2`
        - `description` em `text-sm text-muted-foreground`, `line-clamp-3`
        - `imageUrl`, se houver: `<img loading="lazy" className="max-h-40 w-full rounded-md object-cover" alt="" />`.
          `alt=""` de propósito: a imagem é decorativa aqui, e o título logo ao
          lado já é o texto acessível. `onError` esconde a imagem (site que
          entregou og:image morta não pode virar ícone quebrado).
      - Tokens semânticos apenas; nada de cor direta.
    - CSP: `img-src` já aceita `https:` (verificado no Plano 08.5-14), então a
      imagem de prévia carrega sem mudar nada. Conferir e registrar em vez de
      afrouxar a CSP "por precaução".
  </action>
  <verify>`npm run typecheck` limpo; `npm run build` passa; `grep -n "useRef" src/renderer/src/components/shell/LinkPreviewCard.tsx` mostra a guarda de disparo único.</verify>
  <done>O cartão lê o cache, dispara a busca no máximo uma vez por URL montada, e nunca renderiza estado vazio.</done>
</task>
