## Issues Encountered
- `convex/` is not included in either `tsconfig.node.json` or `tsconfig.web.json` (both have narrow `include` globs scoped to `src/main`, `src/preload`, `src/renderer`), so `npm run typecheck` does not actually type-check `convex/schema.ts` or `convex/auth.config.ts` — it only confirms nothing else broke. This is expected: Convex normally type-checks its own folder via a `convex/tsconfig.json` that `npx convex dev`/codegen generates on first run, and that command is explicitly out of scope for this plan (belongs to checkpoint 02-04). To verify correctness anyway, I ran a standalone `tsc --noEmit` against `convex/**/*` using the exact compiler options Convex's own codegen template uses (`allowJs`, `strict`, `moduleResolution: Bundler`, `target: ESNext`, `module: ESNext`, `isolatedModules`, `noEmit`, plus `@types/node` for `process.env`) — both files compiled with zero errors. This was a throwaway config file in the scratchpad directory, not committed to the repo.
